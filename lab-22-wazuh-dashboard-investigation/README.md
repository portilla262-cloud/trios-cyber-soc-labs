# Lab 22 - Wazuh Dashboard Investigation

## Objective

Use the Wazuh Dashboard **Threat Hunting** interface to investigate security events from a specific Windows endpoint and progressively narrow the event set by agent, time range, rule level, and Windows Event ID until the target event can be inspected in detail.

## Environment

- Authorized TRIOS CYBER laboratory environment
- Existing Wazuh all-in-one deployment
- Monitored endpoint: `Windows-Agent`
- Agent ID: `002`
- Endpoint IP: `10.10.20.30`
- Dashboard area: **Threat Hunting - Events**
- Windows event investigated: `7045`

## Investigation Workflow

The investigation followed a progressive filtering process instead of searching directly for a single record.

| Step | Filter / Action | Purpose |
|---|---|---|
| 1 | Select `Windows-Agent` | Restrict results to one monitored endpoint |
| 2 | Apply a defined time range | Limit the investigation period |
| 3 | Filter by rule level | Reduce the result set by alert severity |
| 4 | Filter Windows Event ID `7045` | Isolate Windows service-creation activity |
| 5 | Open **Document Details** | Validate agent, rule, and event fields |

## Agent and Time-Range Filtering

The Threat Hunting event view was first restricted to `Windows-Agent` and a recent time interval. This reduced the initial event set to telemetry generated by the selected Windows endpoint and established the investigation time boundary.

## Rule-Level Filtering

A rule-level condition was then applied to reduce the result set to alerts matching the selected severity level. This demonstrated how Wazuh can narrow a broad event set before investigating a specific detection.

## Windows Event ID 7045 Investigation

The search was further narrowed to Windows **Event ID 7045**, which isolated the service-creation activity and produced the final record selected for inspection.

## Final Event Details

The selected event was opened in **Document Details** to verify the endpoint and detection context.

| Field | Observed Value |
|---|---|
| Agent ID | `002` |
| Agent name | `Windows-Agent` |
| Endpoint IP | `10.10.20.30` |
| Windows Event ID | `7045` |
| Event source | Service Control Manager |
| Service name | `TriosLab21` |
| Wazuh rule description | `New Windows Service Created` |
| Wazuh rule ID | `61138` |
| Rule level | `5` |
| MITRE ATT&CK technique | `T1543.003` - Windows Service |

## Key Finding

The investigation successfully reduced a broad set of Windows endpoint telemetry to one specific service-creation event. The final record linked `Windows-Agent` to Event ID `7045` and preserved the associated Wazuh rule and MITRE ATT&CK context for focused SOC review.
